# Wrench impact asset

wrench-hit.wav is an original procedurally synthesized dry knock with a subtle metallic ring, created for BE2. No external recordings or samples were used. It is distributed under the repository MIT license.

Format: mono PCM16, 22050 Hz, approximately 115 ms. Playback volume: 0.28. Embedded only in the graphical client; headless builds have no audio dependency.
