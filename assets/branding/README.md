# Retired BlueEngine branding

The Feta white-rat image on the blue tile is retired from reuse at the user's request.
Do not use it in title screens, new projects, documentation, launchers or future
branding unless the user explicitly requests it in a future task. The shared
BlueEngine Games studio card uses simple text.

- `blueengine.ico`: original multi-resolution Windows icon, copied byte-for-byte
  from `scripts/test_lab.ico`.
- `blueengine.png`: matching original PNG.

These files and the legacy copies in scripts/ remain only for compatibility with
existing projects. Preserve their artwork and transparency for those historical
uses. The old make_icon.py script is historical generation code.
