# Wormhole: BlueEngine authoring feedback

Wormhole is an endless native simulation with a game-owned ray-marched tunnel, bounded local rendering coordinates, 64-bit procedural region identities, fixed-step look/pace intentions, exact engine Snapshot continuation and an original adaptive score. The user requested completely unobstructed presentation.

## What worked

- `portable::GameLogic`, `Simulation`, `Snapshot` and the shared client fit an open-ended experience without adding artificial victory or failure. The public verification route crosses a region, changes look and cycles three paces.
- `Scene::render_view` supports custom GLSL while preserving engine lifecycle, input, audio and storage. The field blends shape and color continuously between seeded regions; no unbounded mesh collection is needed.
- Checked named audio banks work for an original score. Four independent phrase lengths and state-driven layer levels provide changing orchestration. The authored stems recur; the combined arrangement changes. PCM/headroom and loop-seam checks are useful, distinct from human listening.

## Friction and changes

1. `show_hud()` hid labels but retained the start/pause panels and transient notices. To meet the user's explicit request for all overlays to be removed, this change adds opt-in `Game::show_overlays()` and `Game::start_automatically()`. Defaults preserve existing games. Wormhole hides all shared/game HUD and panels, starts immediately, and retains pause/save/music keys.
2. A shader Float4 supplied as a tuple containing inferred f64 zero literals was 24 bytes. Macroquad only logged a size mismatch and continued; the first screenshot showed horizontal bands instead of a tunnel. Explicit Vec4 uniforms fixed it. Recommend a typed uniform example in the portable guide; compile success alone cannot verify shader bindings.
3. The starter's named loop banks are relative file paths. Wormhole resolves assets through engine `viewer::devkit::runtime_assets` and configures Macroquad's asset prefix. This supports arbitrary working directories and rejects source fallback in isolated packages without changing the capture argument's working directory.
4. `audio render` requires the bundle parent directory to exist. Creating `assets/audio` first solved the clear validation error. A one-line mkdir in the authoring recipe would avoid this interruption.

## Evidence and limits

The game tests cover deterministic public travel, exact save continuation, 10,000 distinct region keys, large journey coordinates, camera bounds, invalid save rejection and bounded evolving audio mixes. All four score mixes passed clipping/silence/DC/click and wrapped-seam measurement. Native frames are inspected before final publication; package and CI results are recorded in the game status and release workflow. Software capture does not certify physical controller input, audible hardware output or every GPU's performance.
