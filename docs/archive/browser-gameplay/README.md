# Retired browser gameplay (historical source)

Browser/WASM gameplay, static game deployment and Chromium/CDP game gates are retired.
These files preserve implementation history; they are not a runnable toolkit and their
old paths/commands/prerequisites are not supported. Do not install Node/ws, Chromium or
WASM to create BlueEngine games. See docs/PORTABLE_GAMES.md for native 2D/3D composition.

Native Linux/Windows checks, game scenarios, package integrity/resources and isolated
packaged-game smoke remain required. BlueEngineGames still serves download pages;
this retirement affects gameplay in a browser, not its EXE download website.
