# Embertrail 0.2.0 status

Implemented: 32 authored courses, Vesper and a concrete Dawnheart rescue, automatic NPC encounters, eight distinct guardian battles, one fixed jump, independent casting, forgiving buffers and coyote time, tighter braking, pre-arena checkpoints, open root stairways, stable world-space parallax, corrected Mote facing, readable sans typography, and a centered animated village title.

The controller menu includes Atlas, checkpoint/course retries, audio controls, exact current-song WAV download, return to title and quit. Sixteen original multi-section compositions total 18:26. Version 2 migrates old campaign discoveries and safely rebuilds the loaded course geometry.

Twenty gameplay tests cover combat, exact continuation, framed save migration, input and progression. All 32 isolated courses have public-input traversal clears; all eight boss routes independently replay without losing a life, and Vesper reaches the ending. Software keyboard/menu captures and both-size presentation review are recorded in .blue-check. Audio export copies match the selected recording exactly and pause does not restart playback.

The Windows candidate workflow builds the EXE and installer and verifies package isolation, graphical launch, shortcuts, upgrade and save retention. Only a passing candidate is suitable for release. Physical controllers, speaker output and a contiguous human campaign playthrough require device review.
