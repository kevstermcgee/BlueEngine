# Embertrail status

Implemented: 32 explicit courses in eight themed worlds; Mote and five enemy types; eight guardian stages; momentum, sprinting, variable-height jumps, crouching, jump buffering and coyote time; power caches, breakable clay blocks, rolling shells, bouncing ember seeds, secret grottos, 96 optional moon shards, checkpoints, lives, scoring, an unlockable atlas, original pixel artwork and music.

Distribution: native Windows x64 installer EXE. The browser distribution has been retired.

Rules verification covers exact snapshot continuation, collision and combat behavior, save validation, campaign transitions, and terrain routes across all 32 courses. The public-input replay clears the opening course. Windows package, launch and installer evidence is retained by the release repository workflow; a release is published only after those checks pass.

Physical controllers, speaker output, and a complete human playthrough of every course have not been tested.
