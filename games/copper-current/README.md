# Copper Current

Collect eight coil blooms across two lanes while dodging moving storm drums. Survive the full 90-second run with at least one hull point and all coils to win. The copper, teal and plum props are original procedural drawings in src/lib.rs; no shared prop or kit asset is used.

WASD/arrows/controller move; R restarts; K saves; L loads; Esc pauses. Windows is the declared shipping target. Use the engine task packet and project AGENTS.md for checks.
