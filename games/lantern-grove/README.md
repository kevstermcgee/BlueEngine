# Lantern Grove

Collect four golden lanterns and reach the teal exit, avoiding the pink patrol. The 3D garden and a 2D minimap share one deterministic simulation. Desktop: arrows/WASD/controller. Mobile: directional buttons below the game. Progress saves automatically; K/L or the panel use a separate manual checkpoint. Play/install offline in the browser or ship a native desktop package.

Read ../../docs/PORTABLE_GAMES.md and AGENTS.md for the supported workflow.
