Sway is a Windows music visualizer, using BlueEngine's shared simulation and 2D
scene renderer with a streaming PCM analysis client. Linux supports development
checks. The Windows shipping gate verifies executable resources, an isolated
package, single/multiple native Unicode file drops, and synchronized Space pause.

Six visual families, automatic changing chapters, fresh identities per listen,
local media playlists and a ten-second song title are implemented. No persistent
playback HUD. Performance is measured with real native frame intervals.
